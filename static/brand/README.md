# Brand asset provenance

`puskesmas-logo.png` adalah logo Puskesmas yang diunduh pada 19 Oktober 2026 dari halaman resmi pemerintah Puskesmas Muncan:

https://puskesmasmuncan.lomboktengahkab.go.id/uploads/images/Logo_Puskesmas_Tanpa_Background.png

Nama `UPT Puskesmas Suranadi` diverifikasi melalui situs resmi Puskesmas Suranadi milik Pemerintah Kabupaten Lombok Barat:

https://puskesmassuranadi-dikes.lombokbaratkab.go.id/

Sebelum produksi, pemilik layanan tetap perlu mengganti file ini dengan master logo yang mereka sahkan bila terdapat pedoman identitas khusus.
